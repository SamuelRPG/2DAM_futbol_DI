## FUTBOL ##
Repositori per a treballar a l'aula diferents conceptes de React Native.

### Instruccions ###
Caldrà `clonar` aquest repo en el teu sistema local.
1. Obrir un terminal (cmd) i anar a la carpeta on teniu els vostres projectes.
2. Executar  ``` git clone https://github.com/Florida2DAM/Futbol.git ./futbol ```
3. Executar una a una les següents ordres:
   ```
   cd futbol
   npm install
   code .
   npx expo start
    ```
4. Sobre el vscode, creeu una branca nova per a cada `activitat/funcionalitat` que programeu.
